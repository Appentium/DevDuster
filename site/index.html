Free · Source on GitHub · macOS 27 or later · Apple silicon · Signed and notarized

Built for how developers fill a disk

General cleaners skip developer data or treat it as a black box. DevDuster knows what each folder is and what happens when it's gone.

Xcode & Android

DerivedData labelled with the project it belongs to, simulators and runtimes removed through simctl, old NDKs, build tools, system images and AVDs.

Flutter Projects

Every Flutter project on every volume, with build, .dart_tool, Pods and Gradle folders, last activity and one-click Select stale.

Project artifacts

node_modules, Pods, Gradle build and Cargo target, removed only when the matching project file sits next to them.

Caches & logs

40+ rules for SwiftPM, CocoaPods, Homebrew, npm, Yarn, pip, Gradle, Dart pub and Docker.

Uninstaller

Removes apps with their leftovers, background items and Homebrew packages, and finds leftovers of apps already gone.

Disk Map & Large Files

A treemap of any folder or volume, and a finder for large, old files, across internal and external disks.

Every item tells you its risk

You always see a preview first. Move to Trash is on by default, and a hard deny list protects Keychains, iCloud Drive, Photos, Mail and your system.

Safe

Rebuilt automatically on the next build or launch, like DerivedData and package caches.

Review

Downloaded again when needed, like old Gradle caches, DeviceSupport and the pub cache.

Caution

You pick each one, like emulators, SDK versions, simulator runtimes and device backups.

A closer look

Native SwiftUI. No account, no ads, no tracking.

Install

  1. Download DevDuster.zip, unzip it and move DevDuster.app to Applications.
  2. Grant Full Disk Access when asked, so it can measure caches in protected folders.
  3. Optional: allow the helper in System Settings → General → Login Items to use the System section.
/Applications/DevDuster.app/Contents/MacOS/duster scan

The duster command-line tool ships inside the app.
